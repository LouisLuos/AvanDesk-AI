# Shared Module

> Componentes reutilizáveis, pipes, diretivas e modelos de dados comuns.

O módulo `shared` centraliza elementos que podem ser consumidos por múltiplas `features` do sistema:

- Botões, inputs, cards e modais
- Pipes e diretivas genéricas
- Modelos de domínio compartilhados
- Validações e utilitários
