# 💻 AvanDesk-AI — Frontend

> Interface de usuário web do AvanDesk-AI para solicitantes, analistas e gestores da Rede Lúmen Diagnósticos.

## 📋 Visão Geral

O frontend oferece:
- Portal intuitivo para registro guiado de incidentes com validações de dados.
- Painel operacional e kanban de atendimento para analistas de suporte.
- Indicadores de SLA, alertas visuais e dashboard gerencial.
- Interface responsiva com foco em agilidade para ambientes de recepção e laboratório.

## 🛠️ Stack Tecnológica

- **Framework:** Angular
- **Linguagem:** TypeScript
- **Estilização:** CSS / SCSS

Consulte a documentação em [`../docs/`](../docs/) para especificações de requisitos e histórias de usuário.
